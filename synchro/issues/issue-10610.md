> [!NOTE] # [ECF] - Processos alterando a apuração fechada

- No arquivo `EtapasApuracaoProcess` devemos fazer com que as etapas **TRANSFERIR_CSLL_NEGATIVA** e **CALCULA_VALORES_ANTECIPADOS** não alterem as apurações que já estão fechadas.

## Transferir CSLL Negativa
1. Devemos alterar o funcionamento do complemento, que atualmente é anual, para também filtrarmos para mostrar os apenas os períodos que estão abertos.
	- Para isso precisamos adicionar os critérios de limpeza e condições mostrados abaixo.
**Critérios de Limpeza**
![](../../attachments/Pasted%20image%2020250331161311.png)
**Condições**
![](../../attachments/Pasted%20image%2020250331161253.png)
2. Devemos atualizar a apuração apenas dos períodos abertos.
	- A função que usamos após executar o complemento persiste a apuração em todos os períodos, o que precisa ser feito é ignorar os períodos fechados.

## Calcular Valores Antecipados
1. Nessa etapa executamos apenas o método `calculaValorAntecipado` do `ValorAntecipadoBalanceteReceitaEcf`.
	- A apuração é persistida duas vezes, uma no **primeiro periodo** e outro na antecipação 
	- Em ambos os casos não podemos persistir a apuração caso ela esteja fechada para o período

==Obs: os critérios de limpeza citados são apenas exemplos para o periodo, lembrar que também devemos colocar os critérios por MANDT, EMPRESA, ESTR_BALANCO e FORMA_APUR_ECF==
