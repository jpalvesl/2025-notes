```sql
'PLACEHOLDER' = ('$$P_DT_FIN$$', '')) -- YYYYMM

```
2. Buscar o compromisso relacionado a matriz
```SQL
SELECT * FROM SYN4TDF_EVOLUCAO."/SYN/V_COMPROMISSO"
WHERE EMPRESA = ''
AND FILIAL = ''
AND CODIGO_PERIODO = '' -- YYYY
AND CODIGO_OBRIGACAO = 'ECF'
```
