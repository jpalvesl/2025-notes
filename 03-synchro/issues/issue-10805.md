## Frontend
### Geral
- Adicionar no menu as abas referentes as duas novas telas **Parametrização Manual**, **Parametrização Parte B**

### Contábil
- Adicionar campo **Selecionar Lançamentos?**
	- Caso campo esteja marcado como **SIM** os campos **Ind. Saldo Centro Custo**, **Todos Centro Cusos**, **Demonstrar Centros de Custo Vazio** e **Centro de Custo** ficarão desabilitados. Pois a origem dessa informação será de acordo com o lançamento selecionado.
	- Caso o usuário for digitar o valor, será necessário selecionar qual centro de custo será utilizado.
	- Quando o Campo **Selecionar Lançamentos** for **NÃO** os campos os campos **Todos Centros de Custos** ficará desabilitado, porém os outros ficarão habilitados, pois de acordo com o centro de custos selecionado será lançado o valor.
- Ao selecionar a Forma de utilização **10 - Parcial informado** os campos **Todos os centros de Custos** ficará como Não se será habilitado
- Adiciona ação para **Digitar Valores** ou **Selecionar Lançamentos Contábeis** na listagem da parametrização dos valores contábeis
	- Ao clicar para selecionar os valores, irá abrir a tela de parametrizações, apenas com os periodos habilitados para digitarmos os valores
	- Ao clicar para selecionar os lançamentos será feito um somatório dos valores para ser utilizado como valor (Respeitando seus valores em cada período)

CREATE COLUMN TABLE "SYN4TDF_EVOLUCAO"."/SYN/PARAMETRIZACAO_CONFIGURACAO_PARTEB" (
	 "ID" BIGINT NOT NULL ,
	 "MANDT" NVARCHAR(3) NOT NULL ,
	 "EMPRESA" NVARCHAR(4) NOT NULL ,
	 "ANO" NVARCHAR(4) NOT NULL ,
	 "PER_APUR" NVARCHAR(3) NOT NULL ,
	 "TIPO_TRIBUTO" NVARCHAR(5) NOT NULL ,
	 "TIPO_LANCAMENTO" NVARCHAR(2) NOT NULL ,
	 "VALOR_UTILIZADO" DECIMAL CS_DECIMAL_FLOAT DEFAULT 0 NOT NULL ,
	 "IND_VALOR_UTILIZADO" NVARCHAR(1) DEFAULT 'C' NOT NULL ,
	 "CONTA_CONTROLE_CODIGO" NVARCHAR(100) NOT NULL , -- SERIA PRA A GENTE ESCOLHER POR PERIODO CERTO?
	 "TIPO" NVARCHAR(1) NOT NULL , --M/A

	 "IND_CONF_AUTOMATICA" NVARCHAR(1) DEFAULT 'N' NOT NULL ,-- vai ser sempre S?
	 "IND_DIFERIDO" NVARCHAR(1) DEFAULT 'N',
	 "CREATED" SECONDDATE CS_SECONDDATE DEFAULT CURRENT_TIMESTAMP NOT NULL ,
	 "UPDATED" SECONDDATE CS_SECONDDATE DEFAULT CURRENT_TIMESTAMP NOT NULL ,
	 "CHANGED_BY" NVARCHAR(255) DEFAULT '',
	 "DT_LANCTO" NVARCHAR(8) DEFAULT '' NOT NULL ,

CREATE UNIQUE CPBTREE INDEX "CONFIGURACAO_PARTEB_UK" ON "SYN4TDF_EVOLUCAO"."/SYN/CONFIGURACAO_PARTEB" (
