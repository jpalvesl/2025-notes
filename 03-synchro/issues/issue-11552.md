## Contagem  
- A contagem deve ser feita normalmente, visto que se vamos fazer a replica de uma empresa X para uma Y que possui situação especial, devemos trazer todos os registros, mas eles irão iniciar na data de abertura e irão finalizar na data de situação especial para os casos de serem de períodos fora do range da empresa.  
- Talvez seja interessante adicionar mais um texto na mensagem da contagem, pois assim ficaria mais claro, caso o usuário tente replicar para períodos em que a empresa nao esteva em atividade  
  
  
## Delete  
- Deve apagar normalmente com base nos filtros escolhidos  
- Talvez seria interessante já deixar restringido por padrão ao inicio/encerramento da empresa. Isso evitaria mexermos em algo que não faz nem sentido pra empresa  
  
  
## Replica  
  
Casos **Trimestral**  
Trimestral normal -> Trimestral **normal** ==ok==  
Trimestral normal -> Trimestral situação especial **abertura** -> Deve preencher DT_LANCTO com **DT_ABERTURA**, caso seja algum dia anterior a essa DATA  
Trimestral normal -> Trimestral situação especial **encerramento** -> Deve preencher DT_LANCTO com **DT_SIT_ESP_ECF**, caso seja algum dia posterior a essa DATA  
Trimestral normal -> Trimestral situação especial **abertura/encerramento** -> Caso os dois casos acima estejam tratados funcionará normalmente  
  
Casos **Anuais**  
Anual normal -> Anual **normal** ==ok==  
Anual normal -> Anual situação especial **abertura**  
Anual normal -> Anual situação especial **encerramento**  
Anual normal -> Anual situação especial **encerramento**  
  
**Obs**: caso não tenha tratativa pra isso devemos fazer com que caso o período para a replica esteja fora do que a empresa está em atividade, ele seja desconsiderado, pois poderia ocasionar em registros duplicados
